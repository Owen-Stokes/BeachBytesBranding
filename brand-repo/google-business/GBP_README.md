# Beach Bytes — Google Business Profile assets

Images for the Beach Bytes Google Business Profile (Google Search and Maps).
Source file: `Google Business Kit.dc.html` in the design project. Edit there and re-export; don't edit the PNGs.

All files are PNG, sRGB, under 5 MB, which is within Google's upload limits.

## Logo

| File | Size | Use |
|---|---|---|
| `bb-gbp-logo-navy.png` | 1080 × 1080 | **Primary.** Profile → Photos → Logo. Navy background, flat mark. |
| `bb-gbp-logo-white.png` | 1080 × 1080 | Alternate, for a light look. Full-colour mark on white. |

Mark only, with no wordmark: Google shows the logo as a small circle beside the business name, where text would be unreadable. The mark sits inside the circle crop.

## Cover photo

| File | Size | Use |

Google crops the cover differently on phone, desktop and Maps, so key content stays in the centre. Google may still choose another photo to show first. Uploading recent interior and class photos makes the cover more likely to stick.

## Products

Use these in Profile → Edit products, one image per product. Google shows the product name and price under the image, so the tiles stay short.

| File | Product | Suggested category |
|---|---|---|
| `bb-gbp-product-membership.png` | Afterschool Coding Membership | Memberships |
| `bb-gbp-product-dropin.png` | Builder Drop-in | Game building |
| `bb-gbp-product-trial.png` | Free Trial Class | Get started |
| `bb-gbp-product-camps.png` | Coding Camps | Camps |

**Use the 4:3 versions** (1200 × 900): `bb-gbp-product-membership-4x3.png`, `bb-gbp-product-dropin-4x3.png`, `bb-gbp-product-trial-4x3.png`. Google's Edit product frame is wider than square, and the 4:3 images fill it without stretching.
The square 1200 × 1200 versions are kept as backups, or for any platform that shows square images.
Every product links to the matching page on beachbytes.ca.
**Builder Drop-in:** the name stays, but classes are still a weekly scheduled slot. Copy should focus on casual, project-led building ("build your own design", "casual game building"), never "come anytime".
This style is separate from the Square Online badges (`square/`) so the two stores don't look duplicated.
