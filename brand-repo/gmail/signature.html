Gmail signature (new address)

  1. Push the new -canadian GIFs to GitHub first, then wait until the image below shows. If it's a broken icon, Pages hasn't finished setting up yet.
  2. Select everything inside the white box below (click into it, Ctrl+A) and copy (Ctrl+C).
  3. Gmail → ⚙ Settings → See all settings → General → Signature. Delete the old signature, paste, then Save Changes at the bottom.
  4. Send yourself a test email and check the signature animates.
